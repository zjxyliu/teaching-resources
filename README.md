# teaching-resources

用于管理和展示教学演示页面的静态资源仓库。

## 资源组织模式

采用统一分层结构：

`学科 -> 篇 -> 章节 -> 页面(html)`

大学物理按以下章节归纳：

- 第1篇 力学
  - 第1章 运动的描述
  - 第2章 运动定律与力学守恒定律
  - 第3章 机械振动与机械波
- 第2篇 热学
  - 第4章 气体动理论
  - 第5章 热力学基础
- 第3篇 电磁学
  - 第6章 静电场
  - 第7章 稳恒磁场
  - 第8章 电磁感应
- 第4篇 光学
  - 第9章 光学
- 第5篇 近代物理学
  - 第10章 近代物理学基础

该模式支持后续新增其它学科（如教学论）而无需重做导航结构。

## 使用方式

1. 直接在浏览器打开 `index.html`
2. 先选择学科，再按“篇 -> 章节”浏览资源页面
3. 点击资源卡片进入对应演示

## 新增资源（推荐流程）

新增一个页面时，按以下步骤操作：

1. 在 `resources/` 下选择或新建学科目录  
   例如：`resources/大学物理/` 或 `resources/教学论/`
2. 在学科目录下选择或新建“篇”目录（如 `第3篇-电磁学`）
3. 在对应“篇”目录下选择或新建章节目录（如 `第7章-稳恒磁场`）
4. 将新 `.html` 放入对应章节目录
5. 在 `index.html` 的 `catalog` 数组中维护对应学科/篇/章节/页面信息

```javascript
{
    id: "university-physics",
    subject: "大学物理",
    description: "课程资源",
    parts: [
        {
            id: "part-3",
            title: "第3篇 电磁学",
            chapters: [
                {
                    id: "chapter-7",
                    title: "第7章 稳恒磁场",
                    resources: [
                        {
                            id: "demo",
                            title: "示例页面",
                            file: "resources/大学物理/第3篇-电磁学/第7章-稳恒磁场/示例页面.html",
                            description: "页面简介",
                            keywords: ["关键词1", "关键词2"]
                        }
                    ]
                }
            ]
        }
    ]
}
```

完成后刷新 `index.html` 即可在导航页看到新资源。
